# 🌿 Seasonal Portfolio

A beautiful, animated portfolio website that adapts to the current season with dynamic particle effects, glassmorphism design, and smooth animations.

## 🚀 Live Demo

**[View Live →](https://portfolio-blond-one-34.vercel.app)**

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🌸 **Seasonal Themes** | Auto-detects current season (Winter ❄️, Spring 🌧️, Summer ☀️, Autumn 🍂) |
| ✨ **Particle Effects** | Canvas-based animations unique to each season |
| 🎨 **Glassmorphism UI** | Modern frosted glass design with subtle borders |
| 📱 **Fully Responsive** | Works perfectly on all devices |
| ⚡ **Fast Loading** | Optimized loader with progress animation |
| 📝 **Blog Section** | Dedicated page for articles and thoughts |
| 🌙 **Dark Theme** | Premium black aesthetic with accent colors |

## 🛠️ Tech Stack

- **React 19** — UI library
- **Tailwind CSS v4** — Utility-first styling
- **Framer Motion** — Smooth animations
- **React Router** — Multi-page navigation
- **Canvas API** — Particle system
- **Vercel** — Hosting & deployment

## 📁 Pages

| Route | Page |
|-------|------|
| `/` | Home — Hero section with seasonal greeting |
| `/about` | About — Skills, services & stats |
| `/blog` | Blog — Latest articles |
| `/blog/:id` | Blog Post — Full article |
| `/contact` | Contact — Get in touch form |
